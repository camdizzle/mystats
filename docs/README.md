## Build and runtime boundaries

`mystats.py`, both Inno Setup scripts, and the enhancement dependency manifest remain at the repository root as build inputs. The installers do not bundle Python source, the dependency manifest, internal documentation, tests, root game-export samples/logs, Git metadata, build output, or existing Results histories. The `obs_overlay/` and `modern_dashboard/` trees are installed by their dedicated entries. The Chart.js license stays next to the vendored library and is included in the dashboard payload.

This reorganization does not change the installer's existing required build inputs: the rebuilt executable, `README.html`, icon, default settings for a full installation, and any runtime dependencies/sounds must still be present in the build staging folder. No binaries or installers are generated by this cleanup. Exclusion patterns follow [Inno Setup's Files section rules](https://jrsoftware.org/ishelp/topic_filessection.htm).

The exclusions affect future installer payloads; they do not delete existing user data or purge files from a previously installed application. Runtime CSV histories remain managed by MyStats, not by repository cleanup. The deleted sample exports remain recoverable from Git history.
