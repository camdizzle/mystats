# Game CSV field reference

This reference preserves the exact header names and column order of the seven sample game exports removed from the repository. It contains no player records or sample data.

These are input files generated by Marbles on Stream, not files MyStats needs bundled in its application folder. MyStats resolves their configured game SaveGames paths. Game exports may be replaced or updated while results load.

The value kinds below are reading guidance, not a formal game schema. Numeric values and booleans arrive as CSV text; fields can be blank or unavailable in some modes. Preserve identifiers as text. Current parsers accept header aliases/case/punctuation variations and some legacy positional formats; the parser in `mystats.py` remains authoritative.

MyStats creates its own result histories such as `allraces_*.csv`, `tilts_*.csv`, and `checkpoints_*.csv` under its Results directory at runtime. Those histories are separate from the removed samples and must not be deleted during repository or installer cleanup.

## LastSeasonRace.csv

One player result per data row for the latest Race snapshot. Configured as `race_file`.

| Column | Field | Value kind | Meaning |
|---:|---|---|---|
| 1 | `SnapshotId` | identifier | Snapshot identifier supplied by the game; useful for matching related exports. |
| 2 | `Position` | integer | Reported player position or placement. |
| 3 | `Username` | text | Player login/name used as the identity field. |
| 4 | `DisplayName` | text | Player display name. |
| 5 | `Platform` | text | Player platform identifier. |
| 6 | `NameColorHex` | hex color/text | Player name color as supplied by the exporter. |
| 7 | `SeasonPointsEarned` | number | Points earned for this result; distinct from cumulative season points. |
| 8 | `SeasonPointsTotal` | number | Player cumulative season points after the result. |
| 9 | `SeasonWinsTotal` | integer | Player cumulative season wins. |
| 10 | `SeasonMatchesPlayedTotal` | integer | Player cumulative season matches played. |
| 11 | `TimeInRaceSeconds` | seconds | Time spent in the race. |
| 12 | `Eliminated` | boolean | Whether the player/marble was eliminated. |

## LastTiltLevel.csv

Tilt level snapshot. Configured as `tilt_level_file`. Failed-run snapshots are confirmed against subsequent writes before MyStats ends a run.

| Column | Field | Value kind | Meaning |
|---:|---|---|---|
| 1 | `SchemaVersion` | integer | Version of the game export schema. |
| 2 | `SnapshotId` | identifier | Snapshot identifier supplied by the game; useful for matching related exports. |
| 3 | `GeneratedAtUtc` | UTC timestamp | When the game generated the export. |
| 4 | `Status` | text | Exporter-defined state of the snapshot. |
| 5 | `GameMode` | text | Game mode associated with the snapshot. |
| 6 | `SessionType` | text | Game session type supplied by the exporter. |
| 7 | `Level` | integer | Tilt level reported by the game; preserve its numbering. |
| 8 | `Difficulty` | text/number | Exporter-provided level difficulty. |
| 9 | `LevelDurationSeconds` | seconds | Elapsed duration for the Tilt level. |
| 10 | `LevelPassed` | boolean | Whether the Tilt level was completed successfully; may change while results settle. |
| 11 | `PlayerCount` | integer | Number of players in the exported event. |
| 12 | `FinishedCount` | integer | Number of players reported as finished. |
| 13 | `EliminatedCount` | integer | Number of players reported as eliminated. |
| 14 | `TopTilteePlatform` | text | Platform of the top tiltee. |
| 15 | `TopTilteeUsername` | text | Login/name of the top tiltee. |
| 16 | `StandardPointsPerFinisher` | number | Standard level points per finisher; not a substitute for per-player earned points. |
| 17 | `ExpertiseEarned` | number | Expertise awarded for this Tilt level. |
| 18 | `TotalExpertise` | number | Reported cumulative expertise; do not add it again as per-level expertise. |
| 19 | `LiveStreamActive` | boolean | Whether the game reports an active live stream. |
